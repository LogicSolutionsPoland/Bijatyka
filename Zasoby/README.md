# Zasoby — Bijatyka

Katalog na zasoby wykorzystywane podczas rozwoju Bijatyki.

## Atomic Realm

Trzy otrzymane paczki modeli postapokaliptycznych są skatalogowane w [AtomicRealm/README.md](AtomicRealm/README.md). Pliki źródłowe **nie są publikowane w GitHub**, ponieważ ich licencja zabrania redystrybucji, odsprzedaży i ponownego pakowania modeli (także po modyfikacjach).

Własne lokalne kopie ZIP przechowuj w `Zasoby/AtomicRealm/`. Pliki w tym podfolderze są pomijane przez Git, poza dokumentacją i `.gitignore`.

Dopuszczalne jest wykorzystanie i modyfikacja modeli we własnej grze; przed publicznym udostępnieniem plików źródłowych zawsze sprawdź warunki oryginalnej licencji.
